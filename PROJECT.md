# ShorelineOps — project

Senior-living & healthcare dietary operations platform (v5.0.0, `main`):
resident nutrition, allergens, therapeutic diets, IDDSI, compliance, purchasing,
production, foodservice. Dual AGPL/MIT licensing per [LICENSING.md](LICENSING.md).

## Layout (actual)

- `src/` client (Vite + shadcn/ui), `server/` API/engine workspaces, `marketing/`
- `ios/` native Swift companion, `sdk/`, `bin/shoreline.js` CLI, `installer/`
- `docs/` — product/architecture/deployment references; `scripts/` test/build tooling
