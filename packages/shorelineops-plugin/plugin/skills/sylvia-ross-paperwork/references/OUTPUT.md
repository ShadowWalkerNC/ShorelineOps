# Paperwork output behavior

## Quick packet presets

- `weekly`, `weekly paperwork`, `make the weekly packet` → SR-01 + SR-02.
- `today`, `today's cook packet`, or a verified day/date → SR-05 + SR-06 + SR-07 for that date.
- `add summary` → add SR-03.
- `add prep` → add SR-04.
- `add dessert` or `add cold prep` → add SR-08.
- `full daily` → SR-03 + SR-04 + SR-05 + SR-06 + SR-07 + SR-08 for one date.
- `complete packet` → complete packet only when explicitly requested.

## Draft vs final

Use preview/draft output when:

- the menu is not backend-approved;
- the user asks to preview/check layout;
- the requested packet is being reviewed before production.

Use final production output only when the exact current revision is backend-approved.

Never describe a preview as final or an unpersisted chat approval as backend-approved.

## Print-first replies

After successful generation, keep the reply short and operational:

- packet type;
- facility/area;
- week or date;
- page count;
- PDF/file resource.

Avoid repeating the entire menu unless the user asks.
